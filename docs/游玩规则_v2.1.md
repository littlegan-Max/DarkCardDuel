## 一句话

每回合双方同时暗出一张牌，翻开才见分晓。**血只有 1 点**，赢在读到对方下一步，不在牌好。

## 三句话复述

1. 每回合你俩各暗选一张，同时翻开结算——赢的是"读对"，不是"牌好"。
2. 你只有 1 点血和一堆"运"，出牌花运，被打中就死，任何一次读错都可能是最后一次。
3. 贵的牌不是伤害更高，而是**更难被反制**；连招不是更炫，而是用"可预测"换"一次爆发"。

---

## 一、数值

| 项 | 规则 |
|---|---|
| 血 | **1.00**（内部定点 100，界面显示两位小数）。绝大多数攻击牌一击致命 |
| 运 | **初始 0**。**没有每回合自动收入**，只能靠出牌赚 |
| 运的下限 | **-3.0**（比心、觉醒中防反弹的扣运都卡在这个下限） |
| 费用 | 卡表 0~7 费，**1 费 = 10 运** |
| 盾 | 整数张，可跨回合存 |
| 牌库 | 50 张**全对称开放**，无手牌随机、无抽卡、无卡差 |

> 关于"每回合 +1 运"：那是旧文案，**代码里不存在**。想赚运只能出「运」「强化运」「向运葵」，或去抢对方的。

## 二、一回合怎么走

1. **暗选**：双方各自从 50 张里选一张（首回合只能出「运」），同时锁定。
2. **同时翻开**：两边都锁定后才亮牌，谁也不知道对方出什么。
3. **十阶段结算**：按固定顺序跑一遍（见下节），一次算清。

单回合出牌时间：自建房房主可设 5/10/15/20/30/60 秒（默认 20 秒）。

## 三、十阶段结算管线

| 步 | 阶段 | 做什么 |
|---|---|---|
| 1 | REVEAL | 翻开双方牌，进入判定 |
| 2 | 龟派 | 龟派类把对方的牌**转化归属**（见第六节） |
| 3 | 护身符 | 2~3 费的负面技能，指向护身符持有者的一律作废 |
| 4 | 扭转时空 | 置「本回合停摆」标记 |
| 5 | 反制 | 逐张判定能不能挡（优先级见第四节） |
| 6 | 资源与状态 | 扣血/加血/加减运/盾/dot/C4/连招/免疫等全部落地 |
| 7 | 伤害互拼 | **比大小**，决定这一回合谁的伤害真的生效 |
| 8 | 盾保命 | 致命伤时消耗盾，把血拉回该次攻击前 |
| 9 | 死亡判定 | 判负、判同死、判代码杀优先级 |
| 10 | 状态更新 | 记历史、记冷却、发预约运、回合 +1 |

**扭转时空**只跳过第 5、6 步：反制和资源都不结算，但 **dot / C4 的当期跳伤照常**，盾保命照常。

## 四、反制：谁能挡谁

一张牌能不能被挡，**只看它的「可被列」**——卡表里写了谁能挡，就谁能挡；没写的一律挡不了（这是本作最硬的一条）。

判定顺序（先命中先生效）：

| 序 | 防守牌 | 条件与效果 |
|---|---|---|
| 1 | **闪** | 躲开指向自己的负面技能。**躲不了手枪、躲不了代码杀**；对自己用的牌（如自杀）也救不了 |
| 2 | **觉醒中防** | 挡「中防能挡的全部 + 战术核弹」，并按牌面伤害 **×50% 反弹**（上限 0.8）；对比心 → 对方 -1 运；对鄙视 → 对方下回合空过 |
| 3 | **中防** | 挡所有可被列里写了「中防」的牌；被挡的反伤（如长攻分散的空间分散）照算 |
| 4 | **负运** | 只挡降龙 / 小镖 / 长攻分散；挡完对方技能效果**仍然生效**，且自己 -1 运照扣 |
| 5 | **吸 / 超级吸** | 挡下并**夺走对方这回合付的运**；超级吸 ×2。降龙/降飞/飞龙在天被吸时伤害归 0、吸者 +2 运 |
| 6 | **运 / 强化运** | 挡可被列里写了「运」的牌；部分牌被运挡后改为"消耗运"或"抢走本回合所得运" |
| 7 | 其它 | 兜底走卡表 `countered_by` 清单 |

**真伤**只在第 1 步能被闪，第 5 步不吃任何反制，但**照样参与第 7 步的比大小**。

**代码杀**（自杀、小掐/超掐/究掐秒杀乃爆）**盾挡不住、闪躲不了**。

## 五、伤害互拼 = 比大小（本作核心）

第 7 步不是"各打各的"，是**比这一回合谁对对方造成的伤害总量更高**：

- 先按归属方汇总本回合「打向对方的伤害总量」（**含 dot / C4 当期跳伤**）
- **两边总量相同** → 互相抵消，双方伤害全部不生效
- **总量不同** → **只有高的一方生效，低的一方伤害归零**（高方完整生效，不按差额结算）
- 自己挂给自己的 dot（源 = 目标）不参与比较，永远照跳

比完再逐组过两道闸：

1. **酒**：整组总伤害 ≤ 1.0 → 整组免疫
2. **盾**：这一组打死了你，且盾数 ≥ 该牌要求（普通牌 1，核弹/意大利炮 2）→ 消耗盾，血回到这一组攻击前

> 举例：双方都出小镖，其中一方身上 dot 当期跳了 0.2 → 他总量更高，他的小镖 + dot 全生效，对方的小镖归零。

## 六、几套必须单独学的机制

### 龟派族（龟派 / 神之龟派）

- 把对方这回合的牌**转化归属**：对方的自我增益变成你的，对方的攻击变成打他自己
- 你**不用付他的费**，**也不算你出过那张牌**（不进连招、不进冷却、不进三棱镜计数）
- 原来出牌的人照扣费，但**也不算出过**
- 双方同时出龟派类 → **两张都作废**
- 神之龟派：转化后**数值翻倍**（只翻牌面写死的伤害/回血/运/dot/延迟伤害；不翻比例伤害、公式伤害、阈值、计数、时长）
- 反制型牌（吸类）被龟派借走 → 无对象，按无效处理
- 经典博弈：对方出「自杀」你出龟派 → **他活，你死**。这是设计好的，不是 bug

### 连招

- 看「最近几回合**连续**出了什么」，格式如 `中防→中防→吸→中防`
- 中间断一次就归零
- **被挡 / 被吸 / 被闪，仍然算你出过**，连招照常推进
- 龟派借走的牌不算
- 有连招要求的牌，不满足时**不能出**（例外：降飞被运挡后有一次豁免；究掐可无连招使用，只是伤害从 1.4 降到 0.9）

### 冷却 / 不可连用

- 卡表 `CD1` = 出过之后**隔一回合**才能再出；`CD2` 同理
- 吸与超级吸共用同一冷却池：用了一张，另一张也要等
- 微镖「不可连用」= 不能连续两回合出

### 空过（鄙视）

- 被鄙视命中 → **下回合只能空过**（什么都出不了）
- 觉醒中防把鄙视反弹回去 → 反弹者自己下回合空过

### 同死

- 同一回合双方都死：**死于代码杀的一方赢**
- 死法完全一样（都是血量归零且剩余血量相等）→ **这一回合的伤害作废**（代码杀也作废），运/费用/连招/冷却/dot 计时**全部保留**，继续打
- 方向与直觉相反，结算日志里必须显式说明，否则会被当成 bug

### 其它特殊牌

| 牌 | 规则要点 |
|---|---|
| **战术核弹** | 全押：费用 = 你当前全部的运（不足 4 费也能出，扣到 0）；盾需 2 张 |
| **意大利炮** | 7 费、3.0 伤害；盾需 2 张；元首の愤怒生效期内费用降到 2 费 |
| **葵花宝典** | **自己**后续所有技能费用减半，整局有效；不可叠加、不可被净化解除；对可变费用（核弹）无效 |
| **盾** | 首次 4 费，**之后永久 3 费**（按玩家整局计） |
| **净化** | 解除身上所有 dot / C4，并把血回满到历史最高；CD2 |
| **元首の愤怒** | 之后 3 回合内意大利炮降到 2 费 |
| **毒药** | 当前血量的 80%；被"运"挡下则改为 40%（百分比向下取整到 0.01） |
| **三棱镜** | 伤害 = 0.4 + 0.3 × k，k = 本回合出「运/强化运」的人数（负运 -1，龟派借走的不算） |
| **定海神针** | 打 1.6 且自回 0.6；**被挡也照样回血** |
| **长攻分散** | 2.4 伤害；被中防挡 → 挡者 -0.5；被吸 → 出牌者自下回合起每回合 -0.4，持续"被吸走的运数"回合（可被桃桃/净化解除） |
| **比心** | 对方 -2 运，下限 -3.0 |
| **勾魂** | 夺走对方**全部**运（正运才夺，负运不夺）；必须晚于本回合运结算 |
| **自杀** | 自己代码杀自己——用来钓龟派 |

## 七、运经济

| 来源 | 收益 | 备注 |
|---|---|---|
| 运 | +1 运 | 0 费；首回合唯一可出的牌 |
| 强化运 | +2 运 | 1 费 |
| 向运葵 | +1 运（本回合 + 下回合） | 0 费，连招牌 |
| 吸 / 超级吸 | 夺走对方本回合付的费用 | 超级吸 ×2 |
| 勾魂 | 夺走对方全部运 | 3 费 |
| 负运 / 比心 | 削对方运 | 比心可压到 -3.0 |

- 运**没有下限保护**：被压到负数时，1 费以上的牌全都出不了，只剩 0 费牌
- 0 费牌在负运时仍可出

## 九、胜负

- 血量归零，或吃代码杀 → 负
- 双方同回合都死 → 见「同死」
- 回合数上限内的僵局由对局上限与判定规则处理（训练/模拟环境下会记录 `cap_hit`）
